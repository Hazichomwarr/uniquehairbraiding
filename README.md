# Unique Hair Braiding – Website

A modern, conversion-focused landing page built for **Unique Hair Braiding**, a professional hair salon located in Orange, New Jersey.

This website is designed to attract new clients, showcase services, and increase walk-ins and direct calls.

---

## ✨ Features

- Premium hero section with gold typography and animated shimmer
- Sticky transparent navbar with scroll effects
- Services section (scalable & data-driven)
- Gallery showcasing real client work
- Trust / About section with awards and credibility
- Conversion-focused CTA section
- Clean, responsive design (mobile-first)

---

## 🎯 Purpose

This project is built to:

- Increase customer trust through design and visuals
- Highlight real salon work and expertise
- Encourage direct actions (calls, visits, bookings)
- Serve as a scalable base for future features (online booking)

---

## 🛠️ Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
